# Lanka Pay

**A simulated digital payment platform for Sri Lanka.**

Lanka Pay is a university capstone project that demonstrates a full-stack digital payment system built for the Sri Lankan market. It covers user onboarding with NIC/phone verification, wallet management, bank-linked transfers, QR-code payments, and a real-time transaction history — all implemented with a Java/Spring Boot backend, a Flutter mobile app, and a Flutter Web admin dashboard. The system follows a modular-monolith architecture with clean separation between modules, and every integration with external banks or payment networks is handled through a `BankAdapter` interface backed by simulated implementations.

---

> ⚠️ **University Prototype — Simulation Notice**
>
> **All banks, payment networks, and financial institutions in this project are entirely simulated.**
> No real money is moved at any point. Bank responses, account balances, transaction confirmations,
> and OTP delivery are all generated by in-memory stubs labelled **SIMULATED** throughout the
> source code, API responses, and user interface. This project is intended solely for academic
> demonstration and must not be used in any production or real-money context.

## Quick Start

> Full setup instructions will be added as each component is built.

1. Copy `.env.example` → `.env` and fill in your local values.
2. Start a local MySQL instance and create the `lankapay_db` database.
3. Run the backend: `cd backend && ./mvnw spring-boot:run`
4. Run the mobile app: `cd mobile && flutter run`
